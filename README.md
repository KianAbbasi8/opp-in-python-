# Python File Operations Practice

## Description
A collection of Python scripts demonstrating file input/output operations. This repository covers reading from files, writing to files, appending data, and handling text files line by line. Created as part of my foundational Python learning journey with **@Codanics**.

## Files and Topics Covered

| File Name | Topic | Description |
| :--- | :--- | :--- |
| `IO_Oprations_read.py` | Reading Files | Reading entire file content at once. |
| `IO_line_by_line.py` | Line by Line | Reading files line by line efficiently. |
| `write_opration.py` | Writing Files | Writing data to files (overwrites existing). |
| `a_mode_for_write.py` | Appending Files | Adding data to files without overwriting. |
| `create_new_txt.py` | Creating Files | Creating new text files programmatically. |
| `demo.txt` | Sample Input | Sample text file for reading operations. |
| `new.txt` | Sample Output | Example output file. |

## Purpose
To build a strong, practical understanding of file handling in Python—essential for data ingestion, log processing, and working with external data sources in real-world projects.
